# phoenix-training

  Workflow recomendado:

  1. $wayfinder → definir el destino como «una especificación de MVP aprobada y lista para implementar».

  2. Resolver sus tickets de decisión, uno por sesión.

  3. Usar $prototype cuando discutir en abstracto no sea suficiente.

  4. $to-spec → generar .scratch/&lt;app&gt;/[spec.md](http://spec.md).

  5. $to-tickets → crear tickets en .scratch/&lt;app&gt;/issues/.

  6. $implement → implementar cada ticket desbloqueado; internamente usa TDD cuando corresponde y termina

     con code-review.
